# Shady GG Professional Website

Static GitHub Pages website using the two approved Shady GG branding images.

## Files
All files are intentionally kept in the main folder so uploading through the GitHub website is easier:
- `index.html`
- `videos.html`
- `about.html`
- `squad.html`
- `merch.html`
- `contact.html`
- `styles.css`
- `script.js`
- `shadygg-banner.png`
- `shadygg-character.png`

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository.
3. Choose **Add file → Upload files**.
4. Select every file inside the extracted folder and drag them into GitHub.
5. Commit to `main`.
6. Open **Settings → Pages**.
7. Choose **Deploy from a branch**, then `main` and `/ (root)`.
